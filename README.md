# Weather App | Aplicativo de Clima

Aplicação web para consulta de condições climáticas, desenvolvida com **HTML5, CSS3 e JavaScript**.

A aplicação permite pesquisar uma cidade e visualizar informações sobre o clima, com uma interface simples e intuitiva.

**[Acessar o projeto online](https://xisalimax.github.io/weather-js/)** | **[Ver código-fonte](https://github.com/xisalimax/weather-js)**

---

## Sobre o projeto | About the Project

O Weather App é um projeto desenvolvido para praticar e consolidar conhecimentos em desenvolvimento web front-end, manipulação do DOM, requisições HTTP e integração com APIs externas.

The Weather App is a web project designed to practice and strengthen front-end development skills, DOM manipulation, HTTP requests, and integration with external APIs.

## Funcionalidades | Features

- **Busca por cidade:** pesquisa de informações climáticas pelo nome da cidade.
- **Temperatura atual:** exibição da temperatura retornada pela API.
- **Condições climáticas:** apresentação da descrição do clima.
- **Ícones meteorológicos:** representação visual das condições climáticas.
- **Interface responsiva:** layout adaptável a diferentes tamanhos de tela, conforme a implementação atual.

### Features in English

- **City search:** search for weather information by city name.
- **Current temperature:** display of the temperature returned by the API.
- **Weather conditions:** display of the reported weather description.
- **Weather icons:** visual representation of weather conditions.
- **Responsive interface:** layout designed to adapt to different screen sizes, depending on the current implementation.

## Como executar localmente | How to Run Locally

1. Clone o repositório / Clone the repository:

   ```bash
   git clone https://github.com/xisalimax/weather-js.git
   ```

2. Entre na pasta do projeto / Navigate to the project folder:

   ```bash
   cd weather-js
   ```

3. Abra o arquivo `index.html` no navegador ou utilize o Live Server no Visual Studio Code.

   Open `index.html` in your browser or use Live Server in Visual Studio Code.

**Observação / Note:** se o projeto exigir uma chave de API, configure-a conforme as instruções do provedor utilizado. Nunca publique chaves privadas ou credenciais no repositório.

If the project requires an API key, configure it according to the provider's instructions. Never publish private API keys or credentials in the repository.
